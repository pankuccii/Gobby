# Gobby 🦦

> Your tiny clipboard buddy for macOS.  
> It remembers so you don’t have to.

Gobby is a small, native clipboard manager for macOS, built to make copying and pasting a little less chaotic.

It lives quietly in your menu bar, keeps your clipboard history close, and helps you find that one thing you copied five minutes ago.

You know, the thing you definitely thought you’d remember.

And yes, there is an otter involved.

---

## 🦦 Meet Gobby

Gobby is being built around a simple idea:

**Copy things. Find them later. Stay out of the way.**

No giant workspace. No complicated setup. Just a tiny clipboard companion that tries very hard to be useful without becoming another thing you have to manage.

Gobby is an independent project and is currently in active development. Things may change, bugs may appear, and the otter may occasionally make questionable decisions.

We're working on that last part.

---

## ✨ Features

- 📋 **Clipboard History** — Keep track of things you've copied and reuse them later.
- 🔎 **Quick Search** — Find what you're looking for without digging through your history.
- 📌 **Pinned Items** — Keep frequently used clips close at hand.
- 🖼️ **Image Support** — Save and revisit copied images alongside your text.
- 🗓️ **History by Date** — Browse your clipboard history with a little more order.
- ⌨️ **Keyboard-Friendly** — Built to feel at home on macOS.
- 🌗 **Appearance Options** — Light, Dark, and System appearance.
- 🦦 **Native Menu Bar Experience** — Gobby stays nearby without taking over your desktop.

Gobby is still growing. More features and improvements are on the way.

## 📦 Download

The first public preview is available through GitHub Releases.

**[Download the latest release](https://github.com/pankuccii/Gobby/releases/latest)**

Gobby is currently a macOS application. Windows and Linux versions are not available.

### Installation

1. Download the macOS ZIP from the latest release.
2. Extract the archive.
3. Move `Gobby.app` to your Applications folder.
4. Open Gobby and look for the little otter in your menu bar.

That's it. Your clipboard has a new friend.

### A note about the first preview

Gobby is still an early-stage project. The current preview is not yet Developer ID signed or notarized, so macOS may show a security warning when opening it for the first time.

If you trust the application and downloaded it from the official GitHub repository, you can review the warning and use macOS's **System Settings → Privacy & Security → Open Anyway** option where available.

A properly signed and notarized release is planned for the future.

## 🛠️ Build from Source

Want to take a look under the hood? You're welcome to.

Gobby is built with:

- Swift
- SwiftUI
- AppKit
- Native macOS APIs

To build it locally:

1. Clone this repository.
2. Open `Gobby.xcodeproj` in Xcode.
3. Select the Gobby scheme and your Mac as the run destination.
4. Build and run with `⌘R`.

You'll need a compatible version of Xcode and macOS. More detailed build requirements will be documented as the project matures.

## 🔒 Privacy

Your clipboard is personal. Gobby should treat it that way.

Gobby is designed to be **local-first**, with clipboard history stored on your Mac rather than requiring a Gobby cloud account.

The goal is simple: your clipboard manager should help you remember things, not collect them for someone else.

Because Gobby is still in active development, privacy-related behavior and permissions are being reviewed as part of the release process. Please review the source code and release notes if you have specific security requirements.
